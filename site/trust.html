Trust

Security and data handling

Answers to the usual security review questions. Rows marked planned are not built.

01

The SDK

Everything here can be checked in the source.

DependenciescurrentNone at runtime. Python standard library only. Optional extras are opt-in.
LicensecurrentMIT. Source on GitHub.
TelemetrycurrentNone. The only network code is the hosted sink, which runs only when you give it a dashboard API key. local_only=True ignores a key set in the environment.
What traces holdcurrentPatched OpenAI and Anthropic calls record model, token usage, and cost, not prompts or responses. @trace_tool records the first 500 characters of a tool's result or error.
Hosted sinkcurrentBatched on a background thread, gzip on by default, three retries with backoff, an idempotency key per batch, honors 429 Retry-After, and drops the oldest events past 10,000 buffered.
02

Hosted dashboard

Only applies if you send traces to the dashboard.

Sign-incurrentEmail and password, bcrypt hashing, NextAuth JWT sessions.
API keyscurrentSHA-256 hashed before storage, shown by prefix only, revocable.
In transitcurrentTLS, terminated by Vercel and Supabase.
At restcurrentAES-256 via Supabase Postgres encryption.
Tenant scopingcurrentEvery query is scoped by team.
RetentioncurrentDeleted on a schedule: 7 days (Free), 30 (Pro), 90 (Team).
Ingest limitscurrent100 requests per minute per IP, plus a per-plan quota.
Password resetplannedEmail reset flow.
Key rotation and expiryplannedExpiry dates and last-used times.
Roles and audit logplannedOwner, admin, and member roles. Log of key, team, and plan changes.
Deletion on requestplannedAPI for erasure requests. Until then, email us.
SSOplannedFor the Team plan.
Status pageplannedPublic ingest uptime.
