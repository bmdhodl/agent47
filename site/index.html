Case file · the runaway agent

The agent gets three tries. Not thirty.

AgentGuard sits inside your agent's process and watches its calls. When one crosses your limit on spend, repeats, retries, or time, the next call raises instead of going out. Then it hands you a receipt.

Python. MIT. No dependencies, no account, no proxy.

01

Four ways an agent runs away

Each one raises its own exception. Catch it, log it, or let the run end.

File 01Spend
BudgetExceeded

Dollars, tokens, or calls pass the cap you set.

Demo: call 9 hit $1.08 against a $1.00 cap.

Stopped
File 02Loop
LoopDetected

The same tool, called with the same arguments, again.

Demo: search("python asyncio") three times.

Stopped
File 03Retry
RetryLimitExceeded

A failing tool, retried with no ceiling.

Demo: fetch_docs, three tries against a limit of two.

Stopped
File 04Time
TimeoutExceeded

A run that outlives the window you gave it.

Not in the demo. Set TimeoutGuard(max_seconds=120).

02

Three ways in

Pick the one closest to where your agent runs.

  1. Claude Code new in 1.4.1

    A hook that refuses the third identical tool call in a row and a call that already failed twice.

    agentguard hook claude-code --install --write

  2. Any Python script new in 1.4.1

    Runs your script unchanged with the OpenAI and Anthropic clients patched.

    agentguard run --budget-usd 5 agent.py

  3. Your own code

    Patch the client once. Call 21 is refused before it is sent.

    patch_openai(Tracer(), budget_guard=BudgetGuard(max_calls=20))
03

Evidence

The demo, agentguard run, and the hook write every stop to a JSONL file on your disk. In your own code, pass a JsonlFileSink.

$ pip install agentguard47
$ agentguard doctor     # checks the install
$ agentguard demo       # trips the spend, loop, and retry limits
  stopped on call 9: cost $1.08 exceeded $1.00
$ agentguard receipt agentguard_demo_traces.jsonl --format markdown

The receipt lists each stop, the cost the trace recorded, and the trace's SHA-256 drawn as a barcode. Paste it into the pull request that fixed the loop. The hash identifies the file; it is not a signature. agentguard receipt ships in 1.4.1.

04

Rules of engagement

What it will not do, so you do not learn it in production.

  1. It only sees what you point it at. Patched OpenAI and Anthropic clients, LangChain, LangGraph, the Claude Code hook, or your own check() calls. Nothing else on the machine.
  2. It is not an invoice cap. A dollar limit counts usage after each call returns, so the call that crosses the line has already been sent. With a shared local store, sync OpenAI calls and streams reserve before they go out.
  3. It is not a sandbox. Code that skips the SDK is not counted, and anyone with the repo can remove the hook.
  4. It does not phone home. No telemetry. Traces stay on your machine unless you set a dashboard key or configure an export sink, such as OpenTelemetry.
  5. Hosted tools run where it cannot see. From 1.4.1 it patches the OpenAI Responses API and Agents SDK, but a web search or code interpreter call inside one response is not stopped, and background responses are not counted.
