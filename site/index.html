02

Three ways in

Pick the one closest to where your agent runs.

  1. Claude Code new in 2.0.0

    Refuse repeated or repeatedly failed tool calls.

    agentguard hook claude-code --install --write

  2. Any Python script new in 2.0.0

    Patch OpenAI and Anthropic clients as your script runs.

    agentguard run --budget-usd 5 agent.py

  3. Your own code

    Patch your client with a call limit.

    patch_openai(Tracer(), budget_guard=BudgetGuard(max_calls=20))
03

Evidence

Run the offline demo. Inspect each stopped call.

$ pip install agentguard47
$ agentguard doctor     # checks the install
$ agentguard demo       # trips the spend, loop, and retry limits
  stopped on call 9: cost $1.08 exceeded $1.00
$ agentguard receipt agentguard_demo_traces.jsonl --format markdown

The receipt lists stops, recorded cost, and the trace hash. The hash identifies the file; it is not a signature.

04

Rules of engagement

What it will not do, so you do not learn it in production.

  1. Only connected code is checked. Other processes and calls outside the SDK are not covered.
  2. Budgets are not invoice caps. Usage arrives after a call. Shared local stores reserve supported synchronous OpenAI calls before sending.
  3. Not a sandbox. Code can bypass the SDK or remove a hook.
  4. Local by default. Export requires a configured sink or dashboard key.
  5. Hosted tools and background responses are not stopped. Check the full boundary before use.
