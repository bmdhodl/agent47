Try it offline

Three commands. No keys, no network, nothing sent anywhere.

$ pip install agentguard47
$ agentguard doctor      # checks the install and trace writing
$ agentguard demo        # trips budget, loop, and retry limits

$ agentguard quickstart --framework raw --write

The last command writes a starter file for your repo. Quickstarts cover OpenAI, Anthropic, LangChain, LangGraph, and plain Python. Open the quickstart.

02

What it stops

Each limit raises its own exception. Catch it, log it, or let the run end.

  • BudgetExceeded

    Spend, tokens, or call count passed the cap you set.A coding agent re-running the same failing test forty times.

  • LoopDetected

    The same tool was called with the same arguments too many times.search("python asyncio"), search("python asyncio"), search("python asyncio").

  • RetryLimitExceeded

    A tool kept failing and kept getting retried.An API that returns 500 and a retry loop with no ceiling.

  • TimeoutExceeded

    The run took longer than you allowed.A job that should take two minutes, still going at midnight.

03

Two lines around your client

Patch the OpenAI or Anthropic client once. Every chat call after that counts against the limit.

from agentguard import BudgetExceeded, BudgetGuard, Tracer, patch_openai
from openai import OpenAI

patch_openai(Tracer(), budget_guard=BudgetGuard(max_calls=20))
client = OpenAI()

try:
    while agent_wants_more():
        client.chat.completions.create(model="gpt-4o-mini", messages=history)
except BudgetExceeded as stop:
    print(stop)  # call 21 was refused before it was sent
04

What it won't do

Written down so you don't find out in production.

  • It checks calls that go through code you instrument: patched OpenAI and Anthropic clients, LangChain, LangGraph, or your own check() calls.
  • It is not a proxy and does not watch the whole machine. Calls that skip the SDK are not counted.
  • It is not an invoice cap. A dollar or token budget counts usage after each call returns, so the call that crosses the line can finish. With a shared local store, sync OpenAI calls and streams reserve before they are sent.
  • The OpenAI Responses API and Agents SDK are not supported yet.
