Quickstart

From pip install to a stopped agent

Four commands. No account, no API key. You finish with a trace file and a starter you can paste into your agent loop.

pip install agentguard47
01

Check it works

Run these in a clean environment. Everything stays on your machine.

  1. Check the install

    Confirms the SDK imports and can write a trace, then prints what to run next.

    agentguard doctor

  2. Trip the limits

    Runs an offline agent that overspends, repeats a tool call, and retries a failing tool. Each limit stops it and the run is written to JSONL.

    agentguard demo

  3. Read the report

    Cost, guard stops, and timing from the trace the demo just wrote.

    agentguard report agentguard_demo_traces.jsonl

  4. Write a starter

    Drops a small runnable file for your stack into the current directory.

    agentguard quickstart --framework raw --write
02

Pick your stack

Each command prints the smallest working setup for that framework. Add --write to save it.

Plain Python
agentguard quickstart --framework raw
OpenAI
agentguard quickstart --framework openai
Anthropic
agentguard quickstart --framework anthropic
LangChain
agentguard quickstart --framework langchain
LangGraph
agentguard quickstart --framework langgraph
CrewAI experimental
agentguard quickstart --framework crewai

CrewAI is not in the compatibility test job yet. See version compatibility.

03

In your own code

import agentguard

tracer = agentguard.init(
    service="repo-coder",
    budget_usd=5.00,
    trace_file="traces.jsonl",
    local_only=True,
)
# init patches the OpenAI and Anthropic clients. Once recorded spend
# reaches $5, the next patched call raises BudgetExceeded.

The call that crosses $5 has already been sent, so the final total can land above the cap. What each limit stops.
