How we count use

This page view is not an install and not a guard activation. AgentGuard does not ship SDK telemetry. Voluntary demo feedback is inspectable, redacted, and offline until you paste it into GitHub yourself.

Separate measures

Repeat useSame consented reporter on two days in 14Two package downloads
Accepted contributionMerged external PR or accepted issueStars or subscribers

Local demo report

After a local proof, inspect a four-field report with agentguard demo --feedback. Decline by skipping that command. Nothing is sent from the CLI.
